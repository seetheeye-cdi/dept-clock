# PRD – 한국판 국가부채 시계

## 1. 개요
국가부채를 ‘초당 증가’로 시각화해 청년층에게 즉각적 위기의식을 주고, 손쉽게 공유·행동으로 이어지게 하는 웹 서비스.

## 2. 배경 & 문제 정의
- 기존 통계·뉴스는 숫자가 정적이고 어려워 부채 규모가 체감되지 않음.
- 청년층은 사회 문제를 모바일·SNS로 빠르게 소비하고 확산하는 경향이 강함.
- 실시간 카운터 + 개인화(1인당 부담) + 간편 공유 UX로 “감이 안 온다”는 Pain Point 해결 필요.

## 3. 목표
1. 실시간 부채 숫자를 통해 ‘와!’ 하는 체감 제공
2. 카카오톡·인스타 스토리 등 공유 기능으로 메시지 확산
3. 정책 이벤트를 숫자 속도 변화로 연결해 시민 참여 유도
4. MVP 3개월 내 DAU 1만 명 달성

## 4. 타깃 사용자
- 18-35세 청년층 일반 시민
- 모바일 우선, SNS 활발 이용, 공공 현안에 관심은 있지만 통계·경제지식은 낮음

## 5. 핵심 지표 (Primary KPI)
- DAU (일간 활성 사용자)
- 보조: 공유 버튼 클릭률, 알림톡 구독자 수, 세션 길이

## 6. 주요 기능
### 6.1 Core (MVP)
1. 실시간 국가부채 카운터
2. 1인당 부담 금액 카드
3. 정책 이벤트 반영 → 초당 증가 속도 자동 조정
4. 카카오 알림톡 데일리 리포트

### 6.2 Secondary (Phase-2)
1. Methodology(산식·출처) 상세 페이지
2. 공유용 인포그래픽 자동 생성 (카카오·인스타 규격)
3. GDP 대비 부채비율 카드 (확장 옵션)

## 7. 사용자 스토리 (주요 시나리오)
- **US-01** 청년 이용자는 웹을 열자마자 거대한 실시간 숫자를 본다.
- **US-02** ‘1인당 부담’ 카드로 개인 영향치를 이해한다.
- **US-03** ‘공유’ 버튼을 눌러 카카오톡에 링크를 전송한다.
- **US-04** 정책 통과 알림 배너로 속도 변화와 1인당 영향치를 확인한다.
- **US-05** 알림톡 구독을 설정하고 매일 아침 숫자 브리핑을 받는다.

## 8. 기능 요구 사항 상세
| ID | 기능 | 설명 | 우선순위 |
|----|------|------|---------|
| FR-01 | 라이브 카운터 | 초당 업데이트, 탭 비활성 시 보정 | Must |
| FR-02 | 1인당 부담 계산 | 인구 기본 5천만, 설정 가능 | Must |
| FR-03 | 정책 이벤트 반영 | 국회 API/크롤러 → 증가속도 가산 | Must |
| FR-04 | 알림톡 발송 | 매일 09:00, 템플릿 치환 발송 | Must |
| FR-05 | 공유 버튼 | 카카오톡 링크 공유, OG 태그 포함 | Must |
| FR-06 | 인스타 스토리 이미지 | 캔버스→PNG 다운로드 | Should |
| FR-07 | Methodology 페이지 | 산식·출처·오차 범위 설명 | Should |

## 9. 비기능 요구 사항
- 퍼포먼스: 모바일 60fps, LCP < 2.5s
- 신뢰성: 데이터 소스·갱신 시각·추정치 배지 표시
- 접근성: 다크모드, aria-live, 키보드 내비 지원
- 확장성: 국제 버전·추가 지표를 플러그인 형태로 추가 가능

## 10. 기술 스택 (기본)
- Next.js 15, Typescript, TailwindCSS, shadcn/ui, lucide-react
- 데이터: Supabase(PostgreSQL)
- 상태: @tanstack/react-query
- 실시간: Server-Sent Events (SSE)

## 11. 일정 (예시)
| 주차 | 마일스톤 |
|------|-----------|
| 1주 | 디자인 시안, 데이터 소스 연결 목 버전 |
| 2주 | 라이브 카운터 & 1인당 카드 완성 |
| 3주 | 정책 이벤트 파이프라인 목 구현 |
| 4주 | 알림톡·공유 기능 통합, MVP 베타 런칭 |
| 5-6주 | 사용자 피드백, 성능 최적화 |

## 12. 리스크 & 대응
- 데이터 API 제한 → 크롤링 백업, Redis 캐시
- 정치적 민감성 → 중립 어조, 출처 명시, 커뮤니티 가이드라인
- 초기 트래픽 폭주 → Edge-SSE, Vercel 자동 스케일링

## 13. 향후 로드맵
- 정책 뉴스 티커, 다국어 지원, 국제 비교 모듈 추가
- B2B 위젯·API 판매로 수익 다각화
