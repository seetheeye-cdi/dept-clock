# 한국판 국가부채 시계 Information Architecture (IA)

## 1. 사이트맵 (Site Map)

```
한국판 국가부채 시계
├── 홈 (/)
├── 방법론 (/methodology)
├── 구독 관리 (/subscribe)
│   ├── 구독 신청 (/subscribe/new)
│   └── 구독 해지 (/subscribe/cancel)
├── 정책 상세 (/policy/:id)
├── 공유 페이지 (/share/:timestamp)
└── 오류 페이지
    ├── 404 (/404)
    └── 500 (/500)
```

## 2. 사용자 흐름 (User Flow)

### **핵심 작업 1: 첫 방문 및 정보 확인**
1. 사용자가 공유 링크 또는 직접 접속으로 홈페이지 진입
2. 실시간 카운터와 1인당 부담 금액 즉시 확인
3. 스크롤하여 추가 정보 카드들 탐색
4. 출처 배지 클릭 시 방법론 페이지로 이동
5. 공유 버튼 클릭하여 카카오톡/SNS 공유 완료

### **핵심 작업 2: 알림톡 구독**
1. 홈페이지 하단 구독 섹션 확인
2. "매일 아침 브리핑 받기" 버튼 클릭
3. 구독 모달 팝업 열림
4. 전화번호 입력 및 개인정보 처리 동의
5. 구독 완료 확인 메시지 표시
6. 다음날 09:00 첫 알림톡 수신

### **핵심 작업 3: 정책 이벤트 확인**
1. 홈페이지에서 정책 업데이트 토스트 알림 확인
2. "자세히 보기" 클릭
3. 정책 상세 페이지로 이동
4. 정책 내용, 부채 영향도, 1인당 부담 변화 확인
5. 해당 정책 정보 공유 또는 홈으로 복귀

## 3. 네비게이션 구조 (Navigation Structure)

### **글로벌 네비게이션 바 (GNB)**
- 위치: 상단 고정 (64px 높이)
- 구성 요소:
  - 좌측: 로고 "국가부채시계"
  - 우측: 방법론, 구독관리 링크
  - 모바일: 햄버거 메뉴로 축약

### **푸터 네비게이션**
- 위치: 페이지 하단
- 구성 요소:
  - 데이터 출처 링크
  - 개인정보처리방침
  - 이용약관
  - 문의하기
  - 업데이트 시각

### **모바일 네비게이션**
- 햄버거 메뉴 (24px 아이콘)
- 사이드 드로어 형태
- 주요 페이지 링크와 공유 기능 포함

## 4. 페이지 계층 구조 (Page Hierarchy)

```
/ (Depth 1) - 홈페이지
├── /methodology (Depth 2) - 방법론 상세
├── /subscribe (Depth 2) - 구독 관리
│   ├── /subscribe/new (Depth 3) - 구독 신청
│   └── /subscribe/cancel (Depth 3) - 구독 해지
├── /policy/:id (Depth 2) - 정책 상세
├── /share/:timestamp (Depth 2) - 공유 전용 페이지
└── /error (Depth 2) - 오류 페이지
```

## 5. 콘텐츠 구성 (Content Organization)

| 페이지 | 주요 콘텐츠 요소 |
|--------|------------------|
| 홈 (/) | 실시간 카운터, 1인당 부담 카드, GDP 대비 비율, 전일 대비 변화, 정책 이벤트 배너, 공유 버튼, 구독 CTA |
| 방법론 (/methodology) | 계산 공식, 데이터 출처, 업데이트 주기, 오차 범위, FAQ |
| 구독 신청 (/subscribe/new) | 전화번호 입력 폼, 개인정보 동의, 알림 시간 설정, 구독 완료 확인 |
| 구독 해지 (/subscribe/cancel) | 전화번호 확인, 해지 사유 선택, 해지 완료 안내 |
| 정책 상세 (/policy/:id) | 정책명, 시행일, 예산 규모, 1인당 영향액, 부채 증가 속도 변화 |
| 공유 페이지 (/share/:timestamp) | 특정 시점 부채 현황, 인포그래픽, 소셜 메타 태그 |

## 6. 인터랙션 패턴 (Interaction Patterns)

### **실시간 업데이트**
- 실시간 카운터: 1초마다 자동 증가
- 서버 전송 이벤트(SSE)로 정책 변경 시 즉시 반영
- 탭 비활성화 시 백그라운드 계산 후 복귀 시 보정

### **모달 및 팝업**
- 구독 신청: 중앙 모달 (모바일에서는 하단 시트)
- 공유 옵션: 바텀 시트 형태로 카카오톡, 링크 복사 옵션 제공
- 정책 상세: 슬라이드 업 애니메이션으로 전체 화면 표시

### **피드백 및 상태 표시**
- 로딩 상태: 스켈레톤 UI와 스피너
- 성공 메시지: 토스트 알림 (3초 자동 숨김)
- 오류 상태: 인라인 에러 메시지와 재시도 버튼

### **공유 기능**
- 네이티브 공유 API 우선 사용
- 카카오톡 링크 공유 SDK 통합
- 링크 복사 시 클립보드 API 활용

## 7. URL 구조 (URL Structure)

### **일반 규칙**
- 소문자 사용
- 하이픈(-) 구분자 사용
- 간결하고 의미 있는 경로

### **구체적 URL 패턴**
```
/ - 홈페이지
/methodology - 방법론
/subscribe - 구독 관리 허브
/subscribe/new - 구독 신청
/subscribe/cancel - 구독 해지
/policy/:id - 정책 상세 (예: /policy/welfare-expansion-2024)
/share/:timestamp - 공유 페이지 (예: /share/20241220-143000)
```

### **SEO 최적화**
- 정책 페이지: 정책명을 포함한 의미 있는 slug
- 공유 페이지: 날짜-시간 기반 고유 식별자
- 메타 태그: Open Graph, Twitter Card 지원

## 8. 컴포넌트 계층 구조 (Component Hierarchy)

### **글로벌 컴포넌트**
- `Header`: 로고, 네비게이션, 모바일 메뉴
- `Footer`: 링크, 저작권, 업데이트 정보
- `Toast`: 알림 메시지 표시
- `Modal`: 구독, 공유 등 팝업 컨테이너
- `LoadingSpinner`: 로딩 상태 표시

### **데이터 표시 컴포넌트**
- `CounterCard`: 실시간 부채 카운터
- `InfoCard`: 1인당 부담, GDP 비율 등 정보 카드
- `PolicyBanner`: 정책 변경 알림 배너
- `SourceBadge`: 데이터 출처 표시 배지
- `ChangeIndicator`: 증감 화살표와 수치

### **인터랙션 컴포넌트**
- `ShareButton`: 공유 기능 버튼
- `SubscribeForm`: 구독 신청 폼
- `PolicyToast`: 정책 업데이트 토스트
- `CopyButton`: 링크 복사 버튼
- `BackButton`: 이전 페이지 이동

### **레이아웃 컴포넌트**
- `PageLayout`: 기본 페이지 구조
- `CardGrid`: 정보 카드 그리드 레이아웃
- `HeroSection`: 메인 카운터 영역
- `ContentSection`: 콘텐츠 섹션 래퍼

### **폼 컴포넌트**
- `PhoneInput`: 전화번호 입력 필드
- `Checkbox`: 약관 동의 체크박스
- `SubmitButton`: 폼 제출 버튼
- `ValidationMessage`: 유효성 검사 메시지

이 정보 아키텍처는 사용자가 국가부채 정보를 직관적으로 이해하고 쉽게 공유할 수 있도록 설계되었으며, 모바일 우선 접근 방식과 실시간 데이터 특성을 반영하여 구성되었습니다.
