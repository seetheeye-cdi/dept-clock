## Description

# 목적
데이터 출처와 마지막 갱신 시각을 명확히 표시해 신뢰성을 강화한다.

## 요구사항
- 출처명과 마지막 갱신 시각을 메인 화면 상단/하단에 노출.
- 표기 형식: "출처: {sourceName} · 마지막 갱신: {KST YYYY-MM-DD HH:mm}".
- 갱신 지연 경고 배지(예: 1시간 이상 지연 시 "추정") 표시.

## 구현 상세(설계/라이브러리)
- API 재사용: `GET /api/debt-state` 응답의 `sourceName`, `lastUpdatedAt` 활용.
- 시간대 처리: `date-fns-tz`로 Asia/Seoul 고정 변환.
- UI: `shadcn/ui` Badge 컴포넌트. 60초 간격으로 자동 새로고침(React Query refetchInterval).

## 의사코드
```ts
import { formatInTimeZone } from 'date-fns-tz';
const { data } = useDebtState();
const last = data?.lastUpdatedAt ? new Date(data.lastUpdatedAt) : null;
const kst = last ? formatInTimeZone(last, 'Asia/Seoul', 'yyyy-MM-dd HH:mm') : '-';
const delayed = last ? (Date.now() - last.getTime()) > 60 * 60 * 1000 : false;
return (
  <div className="text-xs text-muted-foreground">
    출처: {data?.sourceName ?? '-'} · 마지막 갱신: {kst}
    {delayed && <Badge variant="secondary">추정</Badge>}
  </div>
);
```

## 테스트 전략
- 단위: 시간대 변환/경고 배지 임계치(1시간) 로직 테스트.
- 스냅샷: 서로 다른 소스/시간 표기 UI 스냅샷.
- 통합: API 지연/오류 시 대시(-) 처리 및 재시도 동작 검증.
