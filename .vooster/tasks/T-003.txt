## Description

### 작업 목표
`T-002`에서 생성된 정적 UI에 실시간 카운터 기능을 구현합니다. 이 기능은 서버 데이터를 사용하지 않고, 미리 정의된 목업 데이터를 기반으로 순수 클라이언트 사이드에서 `requestAnimationFrame`을 사용하여 부드러운 숫자 애니메이션을 제공해야 합니다.

### 상세 요구사항

#### 1. 사용자 여정 (구현 범위)
- **사용자** `-(페이지 로드)→` **카운터 초기화** `-(시간 경과)→` **숫자가 매끄럽게 실시간으로 증가**

#### 2. 기능 요구사항 (Functional Requirements)
1.  **컴포넌트 변환**: `app/page.tsx` 파일을 클라이언트 컴포넌트로 전환하기 위해 파일 상단에 `'use client';` 지시어를 추가하세요.
2.  **목업 데이터**: 컴포넌트 내부에 다음과 같은 구조의 목업 데이터를 상수로 정의하세요.
    ```typescript
    const mockData = {
      base_debt_amount: 1200000000000000, // 1,200조
      increase_rate_per_second: 3810000, // 초당 381만원 증가
      population_base: 50000000,
      last_updated_at: new Date().toISOString() // 페이지 로드 시점을 기준 시간으로 설정
    };
    ```
3.  **상태 관리**: `useState`와 `useEffect` 훅을 사용하여 다음 상태를 관리합니다.
    *   `displayedDebt`: 화면에 표시될 총부채 금액 (숫자 타입).
    *   `perCapitaDebt`: 화면에 표시될 1인당 부채 금액 (숫자 타입).
4.  **카운터 로직 (`useEffect` 활용)**:
    *   컴포넌트가 마운트될 때 한 번만 실행되어야 합니다.
    *   `requestAnimationFrame`을 사용하여 애니메이션 루프를 시작합니다.
    *   루프 내에서 현재 시간과 `last_updated_at`의 차이(초)를 계산합니다.
    *   실시간 부채를 계산합니다: `currentDebt = base_debt_amount + (increase_rate_per_second * seconds_elapsed)`.
    *   계산된 `currentDebt`와 이를 `population_base`로 나눈 값을 각각 `displayedDebt`와 `perCapitaDebt` 상태로 업데이트합니다.
    *   컴포넌트가 언마운트될 때 `cancelAnimationFrame`을 호출하여 루프를 정리해야 합니다.
5.  **숫자 포맷팅**: 화면에 숫자를 렌더링할 때 `Intl.NumberFormat('ko-KR').format()`을 사용하여 세 자리마다 쉼표(,)가 포함된 문자열로 변환하여 표시합니다.

#### 3. 데이터 흐름 (Data Flow)
1.  **`Component Mount`**
    *   `→` `useEffect` 훅 실행.
    *   `→` 목업 데이터와 현재 시간을 기준으로 초기 상태 설정.
    *   `→` `requestAnimationFrame` 루프 시작.
2.  **`Animation Frame Loop`** (매 프레임 실행)
    *   `→` 경과 시간 계산.
    *   `→` 새로운 총부채 및 1인당 부채 계산.
    *   `→` `setDisplayedDebt`, `setPerCapitaDebt`로 React 상태 업데이트.
    *   `→` UI 렌더링 (포맷팅된 숫자 표시).
3.  **`Component Unmount`**
    *   `→` `useEffect`의 cleanup 함수 실행.
    *   `→` `cancelAnimationFrame`으로 루프 중단.
