## Description

### 작업 목표
Next.js App Router 환경에서 국가부채 시계의 메인 페이지(`/`)에 대한 UI 전용 목업(mockup) 컴포넌트를 생성합니다. 이 작업은 데이터 연동이나 상태 관리 로직 없이 순수하게 시각적 구조와 레이아웃을 구현하는 데 집중합니다. `shadcn/ui`, `lucide-react`, `Tailwind CSS`를 사용하여 디자인을 구현해야 합니다.

### 상세 요구사항

#### 1. 제품 요약
- 국가부채를 '초당 증가'로 시각화하여 위기감을 체감시키고, 공유를 통해 메시지를 확산시키는 웹 서비스의 메인 페이지입니다.

#### 2. 타겟 사용자
- 18-35세의 모바일 우선 사용자.

#### 3. 디자인 무드
- **Urgent & Serious**: 시급하고 진중한 분위기
- **Data-Driven**: 데이터 중심의 신뢰감 있는 디자인
- **Minimal & Clean**: 직관적이고 깔끔한 인터페이스

#### 4. 컬러 팔레트
- `T-001`에서 정의한 컬러 팔레트를 사용합니다. (Primary: `#FF4C4C`, Background: `#121212`, Foreground: `#F5F5F7` 등)

#### 5. UI 가이드라인
- **컴포넌트**: `shadcn/ui`의 `Card`, `Button` 컴포넌트를 적극 활용합니다.
- **아이콘**: `lucide-react` 아이콘을 사용합니다.
- **레이아웃**: 모바일 우선 반응형 디자인을 적용합니다. 전체 페이지는 수직 중앙 정렬을 기본으로 합니다.
- **폰트**: `T-001`에서 설정한 Pretendard 폰트를 사용합니다.

#### 6. 사용자 여정 (UI 구현 범위)
- **사용자** `-(링크 클릭)→` **랜딩 페이지** `-(즉시 확인)→` **총부채 및 1인당 부채 카운터**

#### 7. 공통 컴포넌트
- **Header**: 로고 텍스트("국가부채시계")와 "방법론" 링크 포함.
- **Footer**: 데이터 출처, 업데이트 시각(목업 텍스트), 개인정보처리방침 링크 포함.

#### 8. 사이트맵 (구현 범위)
- `GET /`: 모든 사용자가 접근 가능한 메인 페이지.

#### 9. 페이지 구현: 홈 (`/`)
- **핵심 목적**: 사용자가 페이지에 진입하는 즉시 부채의 규모와 증가 속도를 시각적으로 체감하게 합니다.
- **핵심 컴포넌트**:
    1.  `Header`
    2.  `HeroSection`:
        *   `CounterCard` (총부채): 매우 큰 숫자로 표시. `aria-live="polite"` 속성 추가.
        *   `CounterCard` (1인당 부채): 보조적인 크기의 숫자로 표시.
    3.  `ActionSection`:
        *   `Button` (공유하기): `Share2` 아이콘과 "공유하기" 텍스트 포함.
    4.  `InfoGrid`:
        *   `InfoCard` (전일 대비): `ArrowUp` 아이콘과 함께 증가액 표시.
        *   `InfoCard` (GDP 대비): 비율(%) 표시.
        *   `InfoCard` (초당 이자): 금액 표시.
    5.  `Footer`
- **레이아웃 구조**:
    *   `flex flex-col items-center justify-center min-h-screen`을 사용하여 페이지 콘텐츠를 수직 중앙에 배치합니다.
    *   모바일에서는 모든 카드가 세로로 쌓이고, 태블릿(md) 이상에서는 `InfoGrid`가 2x2 또는 3x1 그리드로 변경됩니다.

#### 10. 레이아웃 컴포넌트 상세
- **`Header`**
    *   **적용 경로**: `/`
    *   **핵심 컴포넌트**: 좌측 로고 텍스트, 우측 `Button` (variant='ghost') 형태의 '방법론' 링크.
    *   **반응형 동작**: 화면 너비에 관계없이 일관된 형태 유지.

- **`Footer`**
    *   **적용 경로**: `/`
    *   **핵심 컴포넌트**: `div`와 `span`을 사용한 작은 텍스트들. (예: `데이터 출처: 기획재정부 | 최종 업데이트: 2025-09-20`)
    *   **반응형 동작**: 모바일에서는 텍스트가 여러 줄로 표시될 수 있음.
